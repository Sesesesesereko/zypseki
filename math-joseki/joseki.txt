# 共通 | 全単元共通の考え方
## 迷ったときの基本方針
複雑な式・同じ塊が何度も出る :: 共通部分を1文字に**置き換える**（置き換えた文字の**範囲**を必ず確認）
文字が多い・条件式がある :: **1文字消去**、または**最低次の文字**について整理する
2変数で手がかりがない :: 一方を**固定**して1変数として考え、そのあと固定した文字を動かす
$x, y$ を入れ替えても同じ式 :: **対称性**を使う。基本対称式 $x+y,\ xy$ で表す
「少なくとも」「〜でない」 :: **余事象・対偶・背理法**で逆から攻める
一般の $n$ でわからない :: $n=1,2,3$ で**実験**して規則を予想 → 帰納法などで証明
図形・グラフが絡む :: まず**図を描く**。式だけで押し切らない
答えが場合によって変わりそう :: どこで場合分けが起こるか（軸・符号・大小）を先に見つけて**場合分け**
「〜となる条件を求めよ」 :: **必要条件で絞り込み → 十分性を確認**
求めた答えの検算 :: 極端な値・特殊な値（$0$、$1$、対称な場合）を代入して確かめる

# 数学I | 数学I
## 数と式
式の展開が面倒 :: 共通部分を置き換える。$(x+1)(x+2)(x+3)(x+4)$ は**定数項の和が等しい組** $(1,4),(2,3)$ で組む
文字が複数ある因数分解 :: **次数が最も低い文字**について整理する
$x^4+ax^2+b$ 型（複2次式） :: $X=x^2$ と置く。ダメなら $x^2$ の項を調整して**平方の差** $A^2-B^2$ を作る
$a^3+b^3+c^3-3abc$ :: $=(a+b+c)(a^2+b^2+c^2-ab-bc-ca)$
$x^2+y^2$ などの対称式の値 :: $x+y$ と $xy$ を求めて $x^2+y^2=(x+y)^2-2xy$
$x+\dfrac1x$ が与えられた :: $x^2+\dfrac1{x^2}=\left(x+\dfrac1x\right)^2-2$ と次々に作る
分母に根号 :: **有理化**。$\sqrt a+\sqrt b$ には $\sqrt a-\sqrt b$ を掛ける
二重根号 $\sqrt{p\pm2\sqrt q}$ :: 足して $p$、掛けて $q$ になる $a>b$ を探し $\sqrt a\pm\sqrt b$
$\sqrt{A^2}$ :: $=|A|$。中身の**符号で場合分け**して絶対値を外す
整数部分・小数部分 :: 不等式 $n\le x<n+1$ で挟む。小数部分 $=x-(\text{整数部分})$
文字係数の1次不等式 $ax>b$ :: $a>0,\ a=0,\ a<0$ で場合分け（負で割ると不等号が逆）
絶対値を含む方程式・不等式 :: 中身が $0$ になる点で区切って場合分け。$|x|<a \iff -a<x<a$

## 集合と命題
「すべての〜」の否定 :: 「ある〜が…でない」。「かつ」⇔「または」（**ド・モルガン**）
命題の真偽判定 :: 条件を集合で表し $P\subset Q$ を確認。偽なら**反例を1つ**
必要条件・十分条件 :: $p\Rightarrow q$ が真なら「$p$ は十分条件」「$q$ は必要条件」（矢印の**根元が十分**）
直接証明しにくい :: **対偶**を証明する
「無理数」「少なくとも1つ」「存在しない」 :: **背理法**（結論を否定して矛盾を導く）
$\sqrt2$ が無理数の証明 :: $\sqrt2=\dfrac pq$（互いに素）と置き、$p,q$ がともに偶数となる矛盾

## 2次関数
2次関数のグラフ :: **平方完成**して頂点・軸を求める
定義域つきの最大・最小 :: **軸と定義域の位置関係**で場合分け。最小は「軸が左・中・右」、最大は「軸と定義域の中央」で分ける
軸や区間に文字を含む :: 「動くのは軸か区間か」をはっきりさせ、図を並べて場合分け
放物線の決定 :: 頂点が分かる → $y=a(x-p)^2+q$／$x$ 軸との交点 → $y=a(x-\alpha)(x-\beta)$／3点 → $y=ax^2+bx+c$
グラフの平行移動・対称移動 :: 頂点の移動で考える。$x$ 軸対称 $y\to-y$、$y$ 軸対称 $x\to-x$、原点対称は両方
$x$ 軸との共有点 :: 判別式 $D=b^2-4ac$ の符号
2次不等式 $ax^2+bx+c>0$ が全実数で成立 :: $a>0$ かつ $D<0$（$a=0$ の可能性があれば別に調べる）
解の配置（解が $k$ より大きい等） :: **判別式・軸の位置・端点の値 $f(k)$ の符号**の3点セット
2つの解が $k$ を挟む :: $f(k)<0$（$a>0$ のとき）だけでよい
条件式つきの2変数関数 :: 1文字消去して2次関数へ。残った文字の**変域**に注意
条件なしの2変数2次式の最小 :: 一方について平方完成 → 残りを平方完成

## 図形と計量
三角比の相互関係 :: $\sin^2\theta+\cos^2\theta=1$、$1+\tan^2\theta=\dfrac1{\cos^2\theta}$
$180^\circ-\theta$、$90^\circ-\theta$ :: $\sin(180^\circ-\theta)=\sin\theta$、$\cos(180^\circ-\theta)=-\cos\theta$
2辺とその間の角／3辺 :: **余弦定理** $a^2=b^2+c^2-2bc\cos A$
外接円の半径・向かい合う辺と角 :: **正弦定理** $\dfrac a{\sin A}=2R$
三角形の面積 :: $S=\dfrac12bc\sin A$。3辺のみなら $\cos A\to\sin A$ の順（またはヘロン）
内接円の半径 $r$ :: $S=\dfrac12r(a+b+c)$
角の二等分線の長さ :: **面積の和**で立式 $\triangle ABC=\triangle ABD+\triangle ADC$
円に内接する四角形 :: 対角の和が $180^\circ$ → 対角線について余弦定理を**2通り**立てて等置
鋭角・鈍角の判定 :: 最大辺 $a$ について $a^2$ と $b^2+c^2$ の大小
$\sin A:\sin B:\sin C$ が与えられた :: 正弦定理で $a:b:c$ に直す
空間図形 :: 必要な**平面（三角形）を切り出して**平面図形として計算
四面体の体積・高さ :: 底面積×高さ÷3。等しい辺があれば**垂線の足は外心**

## データの分析
分散の計算 :: $s^2=\overline{x^2}-(\bar x)^2$（2乗の平均 − 平均の2乗）
変量の変換 $y=ax+b$ :: 平均 $a\bar x+b$、分散 $a^2s_x^2$、標準偏差 $|a|s_x$

仮説検定（数学I） :: 「偶然起こった」と仮定して確率を求め、基準（例: 5%）以下なら仮説を**棄却**

## 場合の数と確率

1個以上ずつ分ける :: 先に1個ずつ配ってから重複組合せ、または ○の間に仕切りを入れる ${}_{r-1}C_{n-1}$

ある回で初めて／ちょうど $n$ 回目で終わる :: **最後の1回を固定**し、それまでを反復試行で数える
条件付き確率 :: $P_A(B)=\dfrac{P(A\cap B)}{P(A)}$。「原因」を問われたら**樹形図**で全体を整理
期待値 :: （値）×（確率）の総和

$a_{n+1}=pa_n+q$ :: **特性方程式** $\alpha=p\alpha+q$ → $a_{n+1}-\alpha=p(a_n-\alpha)$
$a_{n+1}=pa_n+q^n$ :: 両辺を **$q^{n+1}$（または $p^{n+1}$）で割る**
$a_{n+1}=pa_n+(n\text{ の1次式})$ :: $n$ をずらした式と**引いて階差**を作る／$a_n-(\alpha n+\beta)$ が等比
$a_{n+1}=\dfrac{a_n}{pa_n+q}$ :: **逆数**をとる
$a_{n+2}=pa_{n+1}+qa_n$ :: $x^2=px+q$ の解 $\alpha,\beta$ で $a_{n+2}-\alpha a_{n+1}=\beta(a_{n+1}-\alpha a_n)$ を2通り
$a_{n+1}=pa_n^{\,q}$ :: 両辺の**対数**をとる
$S_n$ と $a_n$ の混ざった漸化式 :: $n$ を1ずらして**引く**
自然数 $n$ についての証明 :: **数学的帰納法**（推定 → 帰納法も定番）

## 統計的な推測
期待値・分散 :: $E(aX+b)=aE(X)+b$、$V(aX+b)=a^2V(X)$、$V(X)=E(X^2)-\{E(X)\}^2$
和と積 :: $E(X+Y)=E(X)+E(Y)$（常に）。独立なら $E(XY)=E(X)E(Y)$、$V(X+Y)=V(X)+V(Y)$
二項分布 $B(n,p)$ :: $E=np$、$V=np(1-p)$
正規分布の確率 :: **標準化** $Z=\dfrac{X-m}\sigma$ → 正規分布表
$n$ が大きい二項分布 :: **正規分布で近似** $N(np,\ np(1-p))$
標本平均 $\bar X$ :: $E(\bar X)=m$、$\sigma(\bar X)=\dfrac\sigma{\sqrt n}$
母平均の信頼区間（95%） :: $\bar X-1.96\dfrac\sigma{\sqrt n}\le m\le\bar X+1.96\dfrac\sigma{\sqrt n}$
母比率の信頼区間（95%） :: $p_0\pm1.96\sqrt{\dfrac{p_0(1-p_0)}n}$
仮説検定 :: **帰無仮説**を立てて標準化、$|Z|>1.96$ なら有意水準5%で棄却（両側）

## 関数と極限
逆関数 :: $y=f(x)$ を $x$ について解き $x,y$ を入れ替え。**定義域と値域も入れ替わる**
合成関数 :: $(f\circ g)(x)=f(g(x))$。**内側の値域**に注意
$\dfrac\infty\infty$ 型 :: 分母の**最高次で割る**
$\infty-\infty$ 型（根号） :: **有理化**
$r^n$ の極限 :: $|r|<1,\ r=1,\ |r|>1,\ r=-1$ で場合分け
直接求められない極限 :: **はさみうちの原理**（評価して挟む）
三角関数の極限 :: $\displaystyle\lim_{x\to0}\frac{\sin x}x=1$ の形を作る（$1-\cos x$ は $1+\cos x$ を掛ける）
$e$ に関する極限 :: $\displaystyle\lim_{h\to0}(1+h)^{\frac1h}=e$、$\displaystyle\lim_{h\to0}\frac{e^h-1}h=1$、$\displaystyle\lim_{h\to0}\frac{\log(1+h)}h=1$
極限値が存在する条件（$\frac00$） :: 分母 $\to0$ なら**分子 $\to0$ が必要** → 必要条件で文字決定
無限級数 :: **部分和 $S_n$** を求めて極限。$a_n\not\to0$ なら発散
無限等比級数 :: 収束 ⇔ $a=0$ または $|r|<1$。和は $\dfrac a{1-r}$
漸化式で定まる数列の極限 :: $|a_{n+1}-\alpha|\le k|a_n-\alpha|$（$0<k<1$）を示してはさみうち
連続性・解の存在 :: **中間値の定理**（$f(a)f(b)<0$ なら間に解）

## 微分法
合成関数の微分 :: **外の微分 × 中の微分**
$x^x$、積・商が多い関数 :: **対数微分法**
陰関数 $F(x,y)=0$ :: $y$ を $x$ の関数とみて両辺微分（$y^2\to2yy'$）
媒介変数表示 :: $\dfrac{dy}{dx}=\dfrac{dy/dt}{dx/dt}$
微分係数の定義の形の極限 :: $\displaystyle\lim_{h\to0}\frac{f(a+h)-f(a)}h=f'(a)$ の形を作る
グラフの概形 :: 定義域・対称性・増減（$f'$）・**凹凸（$f''$）**・漸近線・切片
斜めの漸近線 :: $a=\displaystyle\lim\frac{f(x)}x$、$b=\lim\{f(x)-ax\}$
不等式の証明 :: 差の関数の最小値。符号が分からなければ**もう1回微分**
方程式の実数解の個数 :: **定数分離**してグラフ（$\lim$ で端の挙動も調べる）
平均値の定理 :: $\dfrac{f(b)-f(a)}{b-a}=f'(c)$。**差の形の不等式・極限**で使う
速度・加速度 :: 位置を微分。平面では速さ $\sqrt{(dx/dt)^2+(dy/dt)^2}$
近似式 :: $f(a+h)\fallingdotseq f(a)+f'(a)h$
接線・法線 :: 法線は傾き $-\dfrac1{f'(a)}$

## 積分法
$f(g(x))g'(x)$ の形 :: **置換積分** $t=g(x)$。$\dfrac{f'(x)}{f(x)}\to\log|f(x)|$
$\sqrt{a^2-x^2}$ :: $x=a\sin\theta$ と置換（定積分なら**円の面積**として処理も）
$\dfrac1{x^2+a^2}$ :: $x=a\tan\theta$ と置換
多項式 ×（指数・三角関数） :: **部分積分**（多項式を微分する側に）
$\log x$ を含む :: **部分積分**（$\log x$ を微分する側に。$\int\log x\,dx=\int1\cdot\log x\,dx$）
$e^x\sin x$ 型 :: 部分積分を**2回**して元の積分の方程式を解く
分数関数 :: 分子の次数を下げ → **部分分数分解**
$\sin^2x,\ \cos^2x$、積 :: **半角・積和公式**で次数を下げる
$\sin^mx\cos x$ :: $t=\sin x$ と置換
$\displaystyle\int_0^{\frac\pi2}\sin^nx\,dx$ :: 部分積分で**漸化式** $I_n=\dfrac{n-1}nI_{n-2}$
$\displaystyle\int_{-a}^af(x)\,dx$ :: **偶関数は2倍、奇関数は0**
$\displaystyle\int_0^\pi xf(\sin x)\,dx$ :: $x=\pi-t$ と置換して元の積分と足す
和の極限 $\displaystyle\lim\sum$ :: **区分求積法** $\displaystyle\lim_{n\to\infty}\frac1n\sum_{k=1}^nf\!\left(\frac kn\right)=\int_0^1f(x)\,dx$
定積分の不等式 :: 区間で $f(x)\le g(x)$ → 積分しても成立（等号でない部分があれば $<$）
和 $\sum\dfrac1k$ などの評価 :: **長方形と曲線の面積比較**
媒介変数表示の面積 :: $\int y\,dx$ を $t$ に置換 $\int y\dfrac{dx}{dt}\,dt$
体積 :: **断面積 $S(x)$ を積分**。$x$ 軸回転 $\pi\int y^2\,dx$
$y$ 軸まわりの回転体 :: $\pi\int x^2\,dy$、または**バウムクーヘン** $2\pi\int xf(x)\,dx$
回転軸をまたぐ図形の回転 :: 軸の片側に**折り返して重ね**、外側の曲線を使う
曲線の長さ :: $\displaystyle\int\sqrt{\left(\frac{dx}{dt}\right)^2+\left(\frac{dy}{dt}\right)^2}dt$、$y=f(x)$ なら $\int\sqrt{1+f'(x)^2}\,dx$

## ベクトル
点の位置を表す :: **始点を揃え**、一次独立な2つ（空間は3つ）のベクトルで表す
内分点・外分点 :: $\dfrac{n\vec a+m\vec b}{m+n}$（外分は $n\to-n$）
2直線の交点 :: **2通りに表して係数比較**（一次独立だから比較できる）
3点が一直線上 :: $\overrightarrow{AC}=k\overrightarrow{AB}$
点が平面 $ABC$ 上 :: $\overrightarrow{OP}=s\vec a+t\vec b+u\vec c$、**$s+t+u=1$**
長さ・大きさ :: **2乗して内積で展開** $|\vec a+\vec b|^2=|\vec a|^2+2\vec a\cdot\vec b+|\vec b|^2$
垂直 :: **内積 $=0$**
なす角 :: $\cos\theta=\dfrac{\vec a\cdot\vec b}{|\vec a||\vec b|}$
三角形の面積 :: $\dfrac12\sqrt{|\vec a|^2|\vec b|^2-(\vec a\cdot\vec b)^2}$、成分なら $\dfrac12|x_1y_2-x_2y_1|$
$\overrightarrow{OP}=s\vec a+t\vec b$ の存在範囲 :: **係数の和が1**の形に変形して線分・三角形を読む
$|\vec p+\vec a|$ の最小 :: $\vec p$ を $t$ で表し $t$ の**2次関数**、または図形的に垂線
平面への垂線の足 :: 平面上の**2つのベクトルと垂直**（内積0を2本）
外心・垂心の位置ベクトル :: 外心は「中点から垂直」、垂心は「垂直」を**内積で連立**
内心の位置ベクトル :: $\dfrac{a\vec A+b\vec B+c\vec C}{a+b+c}$（$a,b,c$ は対辺の長さ）
球面 :: $|\vec p-\vec c|=r$。平面との交わりは**中心からの距離**と三平方

## 平面上の曲線と複素数平面
2次曲線の標準形 :: 楕円 $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1$（焦点 $c^2=a^2-b^2$）、双曲線（$c^2=a^2+b^2$）、放物線 $y^2=4px$
2次曲線の接線 :: 接点 $(x_1,y_1)$ で $\dfrac{x_1x}{a^2}+\dfrac{y_1y}{b^2}=1$（双曲線は $-$）
楕円上の点の最大・最小 :: **媒介変数** $(a\cos\theta,\ b\sin\theta)$ → 合成
平行移動した2次曲線 :: **平方完成**して標準形に戻す
極座標・極方程式 :: $x=r\cos\theta,\ y=r\sin\theta,\ r^2=x^2+y^2$ で直交座標へ
複素数の積・商 :: **極形式**：絶対値は積・商、偏角は和・差
$z^n$ の計算 :: 極形式にして**ド・モアブルの定理**
$z^n=a$ の解 :: $z=r(\cos\theta+i\sin\theta)$ と置いて絶対値・偏角比較。解は**正 $n$ 角形**の頂点
点の回転 :: 点 $\alpha$ のまわりに $\theta$ 回転：$w=(\cos\theta+i\sin\theta)(z-\alpha)+\alpha$
実数・純虚数の条件 :: $z$ が実数 ⇔ $\bar z=z$、純虚数 ⇔ $\bar z=-z$（$z\ne0$）
$|z|=1$ :: $\bar z=\dfrac1z$ を使って共役を消す
3点 $\alpha,\beta,\gamma$ の位置関係 :: $\dfrac{\gamma-\alpha}{\beta-\alpha}$ を計算：実数 → **一直線**、純虚数 → **垂直**、偏角 → **角**
円・垂直二等分線 :: $|z-\alpha|=r$ は円、$|z-\alpha|=|z-\beta|$ は垂直二等分線
$|z-\alpha|=k|z-\beta|$ :: 両辺**2乗して** $z\bar z$ で展開（アポロニウスの円）
$w=f(z)$ で $z$ が動くときの $w$ の軌跡 :: $z$ を $w$ で表し、**$z$ の条件に代入**
