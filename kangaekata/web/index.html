数I数と式・論証

この単元の見方

式の問題は「かたまり」と「対称性」を探す

式の計算でつまずくのは、式を「文字の寄せ集め」として見ているときです。上手な人は、式の中に同じ形のかたまりや入れ替えても変わらない形を探しています。それが見つかれば、式は一気に簡単になります。

  • 同じ形が2回以上出てきたら、それを1文字とみる（置き換え）
  • xxx と yyy を入れ替えても変わらない式は、x+yx+yx+y と xyxyxy だけで書ける
  • 証明で、示したいことを直接言うのが難しければ逆から（対偶・背理法）攻める
見分け方

同じ形が2回あれば置き換える。入れ替えて同じなら対称式。「〜でない」「無理数」と言われたら背理法。

数I2次関数

この単元の見方

2次関数は「グラフを描いて、軸がどこにあるか」がすべて

最大・最小、解の配置、不等式。2次関数の問題は見た目が違っても、結局は放物線を描いて、見たい場所の高さを読むだけです。文字が入って難しく見えても、「軸が動く」か「範囲が動く」かのどちらかにすぎません。

  • 最初にやるのは平方完成して軸と頂点を出すこと
  • 文字があるなら、動く軸（範囲）の図を何枚か描く。場合分けはその図から自然に出てくる
  • 式だけで考えない。必ず図を描く
見分け方

2次式が出たら、まず平方完成して図を描く。文字が入っていたら「何が動くのか」を確認する。

数I図形と計量

この単元の見方

三角形は「わかっているもの」と「欲しいもの」で定理が決まる

正弦定理・余弦定理・面積公式は、使う場面がはっきり分かれています。迷ったら、今わかっている辺と角と、欲しいものを図に書き込みます。そうすると使う定理が自動的に決まります。

  • 2辺とその間の角、または3辺 → 余弦定理
  • 向かい合う辺と角のペア、または外接円 → 正弦定理
  • 複雑な図形は、計算できる三角形を切り出す。同じ量を2通りに表すと方程式ができる
見分け方

図にわかっている量を書き込み、「三角形が1つ決まるか」を見る。決まらないなら、同じ量を2通りに表せないか考える。

数A場合の数・確率

この単元の見方

確率は「全部区別する」と「状態で考える」

確率で間違える原因の多くは数え方です。同じ色の玉や同じ目でもすべて区別すれば、どの場合も同じ確率で起こり、ただ数えるだけになります。回数が nnn 回のように一般化されたら、細かい経過は追わず、今どの状態にいるかだけを見ます。

  • 同じものでも区別して数える（区別しないと確率が狂う）
  • 数える前に「逆側（余事象）のほうが簡単では？」と確認する
  • 「ちょうど」は数えにくい。「以下」で数えて引き算する
  • nnn 回の試行は、状態を少なくまとめて推移（漸化式）で考える
見分け方

「少なくとも」「〜の倍数」→ 余事象。「ちょうど最大が〜」→ 以下の引き算。「nnn 回後」→ 状態の推移。

例題 7余事象で数える場合を減らす

さいころを3回振るとき、出た目の積が4の倍数になる確率を求めよ。
自分で解いてから、頭の中の実況を見る
  1. 1考える
    4の倍数になる場合は「4が出る」「偶数が2回」などいろいろあって、数えると漏れそう。逆側を見る。
  2. 2考える
    4の倍数でない ⇔ 積に含まれる2が1個以下。これなら2通りしかない。
  3. 書く
    ① 全部奇数：(12)3=18\left(\dfrac12\right)^3=\dfrac18(21​)3=81​
  4. 書く
    ② 偶数がちょうど1回で、それが2か6（4は不可）：3⋅26⋅(12)2=143\cdot\dfrac26\cdot\left(\dfrac12\right)^2=\dfrac143⋅62​⋅(21​)2=41​
  5. ポイント
    「4の倍数」を「2が何個あるか」と言い換えたことで、数える対象がはっきりした。
  6. 答
    1−(18+14)=581-\left(\dfrac18+\dfrac14\right)=\dfrac581−(81​+41​)=85​

数A整数

この単元の見方

整数の道具は「範囲を絞る」と「性質を使う」の2つだけ

整数問題は解き方が見えにくい分野ですが、使える道具は実は2つしかありません。問題を見たら、まず「この問題はどっちで攻めるか」を考えます。

  • 範囲を絞る：不等式で「xxx は1〜3のどれか」のように候補を有限個にし、あとは調べ尽くす
  • 性質を使う：約数・倍数・余りを使い、「6の約数しかありえない」「3で割った余りは0か1」のように候補を決める
  • 文字が多くて式が1本しかないとき、等式だけでは解けない。整数であることが唯一の手がかり
見分け方

積の形が作れそう → 約数（性質）。分数の和や大小がある → 不等式（範囲）。「〜の倍数を示せ」→ 余り（性質）。

ベクトルの問題は、図の中のすべての点を基準の2本（a⃗,b⃗\vec a,\vec ba,b）で表せば、あとは計算です。交点は2通りに表して比較し、長さや角は内積で処理します。
